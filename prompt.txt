Build Pulse Reach — an internal lead generation
and email outreach automation tool for PulseHub.

This is a separate project from HMS.
Do not mix with existing HMS codebase.

---

TECH STACK

Frontend: Next.js
Database: Neon PostgreSQL
APIs: Outscraper, Instantly
Hosting: Vercel

---

WHAT TO BUILD

1. LEAD COLLECTION

Search form with:
- Country dropdown
- City input
- Results limit selector (100, 200, 500)
- Search button

On search:
- Call Outscraper Google Maps API
- Query: "hostel [city] [country]"
- Extract: name, email, phone, website, address, city, country
- Filter out leads with no email
- Remove duplicates by email
- Save to Neon database
- Show results in table

Results table columns:
- Hostel name
- Email
- Phone
- City
- Country
- Website
- Status (New, Added to Campaign, Replied, Converted)

2. CAMPAIGN MANAGEMENT

Campaign creation:
- Campaign name (auto: "Pulse HMS - [Country] - [Date]")
- Select leads from database
- Filter by country or city
- Select all or individual leads
- Click Launch Campaign button

On launch:
- Create campaign in Instantly via API
- Upload selected leads to campaign
- Activate campaign
- Update lead status to "Added to Campaign"
- Show success message with campaign link

Campaign list page:
- Show all active campaigns
- Campaign name
- Leads count
- Emails sent
- Open rate
- Reply rate
- Status

3. LEADS DATABASE

Full leads management:
- View all collected leads
- Filter by country, city, status
- Export to CSV
- Delete duplicates
- Mark as replied or converted
- Add notes per lead

4. DASHBOARD

Simple overview showing:
- Total leads collected
- Total emails sent
- Total open rate
- Total reply rate
- Total converted
- Active campaigns count
- Leads by country chart

DATABASE SCHEMA

Table: leads
- id
- hostel_name
- email
- phone
- website
- address
- city
- country
- status (new, campaign_added, replied, converted)
- notes
- created_at
- updated_at

Table: campaigns
- id
- name
- instantly_campaign_id
- country
- city
- leads_count
- status
- created_at

Table: campaign_leads
- id
- campaign_id
- lead_id
- added_at
